# TRENDORA — Define Your Style 

A modern fashion e-commerce website built using HTML, CSS and JavaScript.

TRENDORA provides a complete front-end shopping experience with user authentication, product browsing, search and filtering, wishlist, cart management and a demo checkout flow.

## 🚀 Live Demo

🔗 [View TRENDORA Live](https://alokgupta1234.github.io/TRENDORA/)

## ✨ Features

- 🏠 Modern landing page with animated UI
- 🔐 Sign In and Sign Up functionality
- 👤 User profile and logout
- 🛍️ Product browsing and product details
- 🔎 Product search
- 🏷️ Category-based filtering
- 📊 Price, rating and size filters
- ❤️ Wishlist functionality
- 🛒 Shopping cart with quantity controls
- 📦 Demo checkout and order confirmation
- 🔥 Offers and countdown timer
- 📧 Newsletter subscription interface
- 📱 Responsive design for different screen sizes
- 💾 Cart, wishlist and user data stored using browser localStorage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Browser LocalStorage
- Git & GitHub
- GitHub Pages
